## 零、一句话读懂这栋建筑

**不是"云"，是一只歪掉的斗笠。**

- 一侧**短而陡**、竹篾格网近乎垂直立起、垂到近地（R=4.10 m）
- 对侧**长而缓**、薄檐平飘外展、悬在 2.45 m（R=6.80 m）
- 三处低开口是**拱腿**：外缘在最外一圈近垂直下探到地面，能穿行
- 中心是**一束竹竿**（不是柱子）：柱脚 φ0.67 扎紧 → 一路单调张开 → 柱顶 φ2.10 接屋面
- 顶上采光口**沉在脊线内侧**（火山口），洞口低于峰顶 0.58 m
- 屋面构造：曲梁 → 竹篾格网 → 有机玻璃（连续）→ 苇席 → 卷材 → 竹瓦（只盖中上部）

认知错了，参数调一万遍也不对。**先认形体，再动手。**

def R_edge(th):
    w = _crag(th)                                   # 陡侧权重 ∈[0,1]
    r = R_TAIL + (R_CRAG - R_TAIL) * w
    r += 0.20 * math.cos(2*(th-TH_R) + 0.4)         # 双频起伏
    r += 0.13 * math.cos(3*th + 1.0)
    for d, amp in zip(DIPS, (0.58, 0.30, 0.52)):    # 开口处外伸
        r += amp * math.exp(-((ang_diff(th, d)/math.radians(30))**2))
    return r

def E_edge(th):
    w = _crag(th)
    z = Z_TAIL + (Z_CRAG - Z_TAIL) * (w ** 1.2)
    for d, dep in zip(DIPS, (1.55, 0.25, 1.55)):    # 开口下探
        z -= dep * math.exp(-((ang_diff(th, d)/math.radians(18))**2))
    z = 1.35 + 0.5*((z-1.35) + math.sqrt((z-1.35)**2 + 0.010))   # 外缘抬升(高架檐下)

## 三、尺寸对表（图纸 ↔ 模型）

| 项 | 图纸（28.70 px/m 量测） | 模型 | 偏差 |
|---|---|---|---|
| 屋脊高 | 6.93 – 7.07 m | **6.97 m** | +0.5% |
| 北立面宽 | 17.98 m | 17.89 m | −0.5% |
| 剪影最大宽 | 17.94 m | 17.56 m | −2% |
| 采光口直径 | ≈1.1–1.3 m | 3.09 m（含洞沿下沉范围） | 见下注 |
| 剪影 W99（99% 高处的宽） | 0.87 m | 1.10 m | +26% |
| 剪影 W95 | 2.16 m | 6.10 m | **仍偏宽，圆肩比实物钝** |
| 柱脚 / 柱顶直径 | 0.80 / 2.64 m | 0.67×1.47 / 2.10×1.47 | 略细 |
| 总包围盒 | — | 17.89 × 17.56 × 7.39 m | 609 对象 |

**已知未解的两处**（下次可以接着做，别当成已完成）：
1. **W95 偏宽**：顶部"圆肩"比图纸钝，根子在陡侧/长尾侧的坡度结构，不是洞口。
   再锐一档（`RIM_SIG=0.085`）只收窄 0.85 m 而峰高冲到 7.30 m，弃用。
2. **三处开口方位的母线末段仍有弯折**（拱腿下探所致）。要柔化得改 `dip_w` 的过渡，
   但会牵动"落地形态"，属改设计尺度的事，需用户点头。

## 四、版本史 —— 每次都是"用户一句话 + 一个真根因"

| 版本 | 用户说 | 真正的问题 |
|---|---|---|
| v1→v2 | 开口有那么大吗？立柱有那么粗吗？ | 开口偏心 r=0.75；柱是 φ3.9 实心圆锥筒（当成了小房间） |
| v2→v3 | 核对细节 | 整体偏小 30%；竹篾改菱形交叉；竹梁 φ13→8 cm |
| v3→v5 | — | 像素级量测重标定；筒改 16 竿束筒；**玻璃别铺满屋面** |
| v5→v11 | — | 推翻"均匀涟漪"，改成**歪斗笠**；删掉自己臆造的两道竹坐凳 |
| v11→v12 | 中间的柱子还是有点问题 | 柱做成"竹编灯笼"（沙漏收腰）；实物是一路张开的喇叭，柱顶要接住内环 |
| v12→v13 | 核对细节继续修改 | "两层感"：屋面梁在洞口断头，柱是独立编的筐 → **一条曲线连续走屋面+筒身**，32 肋对 32 梁 |
| v13→v14 | 两侧为啥不着地？悬空了 | `E_edge` 末尾 `max(z,0.40)` 把整圈抬平；**同时发现比例尺量出 1.4 倍差** |
| v14→v17 | 这块这么稀疏结构对吗 | **`AddPipe` 只铺半根曲线**，10 处杆件全只有一半长 |
| v17→v18 | 周围绿地座椅石头都删了 | 只留核心建筑；删臆造场地件 |
| v18→v19 | — | 按 28.70 px/m 整体 ×1.47；开口改"垂直下探成拱腿" |
| v19→v20 | 顶部稍微尖一点 | **"平盘"就是洞口本身**（W99 下限 = 洞径）→ 洞口下沉做火山口 |
| v20→v21 | 那三个灰色东西删了 | 自己补的条基础 + 钢板，图纸上没有 |
| v21→v22 | 中间的也删了，地面铺一层 | 删中心垫层；铺 100 m 素地坪（36 m 会看出板边） |
| v22→v24 | 顶面平视应该在一条直线上 | 用户要**斜直线**不是水平线；降坡与半径共用同一幂 → 母线线性化 |
| v24→v25 | 线框和着色黑，渲染纯白素模 | 见 `styling.md` 第 2 节 |

**教训串起来看**：用户每次只说一句模糊的话（"还是有点问题"），
真根因都在**代码**（clamp、AddPipe、幂函数）或**量测方法**（循环论证、角落取背景）里，
不在"审美"上。**先量化，再改。**
