## 一、开工前必须从图纸里挖出三件事

跳过这三步，后面每一版都会被"再修正一下精度"打回来。

### 1. 比例尺（别用"假设总高"反推）
图纸角落的刻度尺做像素量测，**四段互校**：

```
刻度 1639.5 / 1696.5 / 1783.0 / 1926.5 px  ↔  0 / 2 / 5 / 10 m
→ 28.70 px/m（四段一致才可信）
地面线 y=654 → 屋脊 y=? → 净高 6.93 m
```
竖向与水平各算一个倍数：**接近 → 整体等比缩放；差很多 → 比例本身错了。**
本项目：竖向 ×1.450 / 水平 ×1.483 → 整体 ×1.47。

### 2. 剖面母线的**形状类型**（直线 / 弧 / 折）
这一步决定 `surf()` 怎么写，也是"顶面平视应该是一条直线"那类反馈的根。
- 逐点采样剖面 → 拟合 → 看残差
- 直线：`z` 与 `r` 成线性（用同一个 `t**POW` 分配 r 和 z）
- 弧：smoothstep / 幂函数
- **别混着来**。混了就是"怎么调都弯"。

### 3. 构造层的**叠放顺序与各自覆盖范围**
按分析图/实拍定，别自己发明：
```
弯曲竹梁(结构) → 竹篾格网(结构层) → 有机玻璃(透明外皮,连续铺满)
              → 苇席 → 防水卷材 → 竹瓦(只盖中上部,像"斗笠",自由边以外露格网)
```
关键认知：**竹瓦不是铺满整个壳**。铺满就会把"能看穿的格网+玻璃"盖掉，
顶视图也读不出三处开口。用 `TE(th)` 控制铺瓦边界。

## 二、参数曲面的写法（唯一形状源）

**一个 `surf(th, t, offset)` 管住整个形体**，所有面层、梁、格网都从它取点。
改形状只改文件头部常量区，永不散落在各处。

```python
def surf(th, t, offset=0.0):
    R = R_edge(th)                       # 外缘半径：方位相关（非对称的关键）
    r = R0 + (R - R0) * t**RT_POW      # 内环 -> 外缘
    E = E_edge(th)                       # 外缘标高：方位相关
    H = CREST_Z
    z = H + (E - H) * t**RT_POW        # 与 r 共用同一幂 -> 母线是直线
    z -= RIM_DIP * math.exp(-(t / RIM_SIG)**2)   # 洞口下沉（火山口）
    x, y = r*math.cos(th), r*math.sin(th)
    p = (x, y, z)
    if offset:
        p = tuple(a + b*offset for a, b in zip(p, surf_n(th, t)))
    return p
```

**非对称靠两个方位函数**：`R_edge(th)` 控制"哪边长"、`E_edge(th)` 控制"哪边高"。
本项目本质是**一只歪掉的斗笠**：陡崖侧 R=4.10 垂到近地，长尾侧 R=6.80 悬在 2.45 m。
识别出这个东西，比抠一百个参数有用。

**法向偏移**（不是 Z 偏移）：
```python
def surf_n(th, t, eps=1e-3):
    p0 = surf(th, t); pt = surf(th, min(1, t+eps)); pth = surf(th+eps, t)
    u = [a-b for a,b in zip(pt, p0)]; v = [a-b for a,b in zip(pth, p0)]
    n = (u[1]*v[2]-u[2]*v[1], u[2]*v[0]-u[0]*v[2], u[0]*v[1]-u[1]*v[0])
    L = math.sqrt(sum(a*a for a in n)) or 1.0
    return tuple(a/L for a in n)
```

**反解 t**（给定半径求参数，用于把梁/格网对齐到洞口或柱顶）：
```python
def invert_t(th, r):
    frac = (r - R0) / (R_edge(th) - R0)
    return max(0.0, min(1.0, frac)) ** (1.0/RT_POW)
```

## 三、图层规范

**图层 = 构造层，一个图层一类构件，图层色 = 材料色。**
不要给对象单独上色（除非做黑白版）。

```python
if not rs.IsLayer(name):
    rs.AddLayer(name)
    rs.LayerColor(name, packed(r, g, b))   # 新建时才有效
else:
    rs.LayerColor(name, packed(r, g, b))   # 已存在必须补这一句（AddLayer 是空操作）
rs.CurrentLayer(name)                       # 建对象前切层；ObjectLayer 不会自动建层
```

## 四、构件密度（"太稀疏"的量化阈值）

用户说"这块这么稀疏结构你自己看看对吗"时，先量化再改：

| 构件 | 阈值 | 备注 |
|---|---|---|
| 竹篾单族条数 | 160 条 | 200 条像铁丝网，160 + 径 0.016 像竹编 |
| 篾径 | 0.016 m | 实物约 2.6 cm 宽 |
| 放射曲梁 | 32 根 | **必须 = 柱肋数** |
| 柱肋 | 32 根 | |
| 环向瓦阶 | 24 道 | 竹瓦是**横向层叠**，不是竖向瓦垄 |
| 径向分缝 | 0.011–0.013 m | 与瓦阶配合才读得出瓦垄 |
| 屋面网格细分 | 180 × 48 | 低于这个瓦面自由边会锯齿 |
| 筒身环箍 | 9 道 | 柱脚扎紧 |

**密度不是越高越好**：乘 2 倍对象数、建模时间线性上升，视觉收益很快饱和。
先到阈值，再问用户要不要更细。

## 五、精细度自查清单（交付前逐条过）

对着渲染图逐条问，答不上就说明没核对：

1. **开口**：形状、直径、位置（居中还是偏心）、净高。是不是比实物夸张？
2. **中心柱**：最大/最小直径、是喇叭还是沙漏、柱顶是否接住屋面内环、
   柱肋数是否等于屋面梁数。
3. **接地**：整圈外缘有没有悬空？靠的是真落地还是 clamp 出来的？
   拱腿是"垂直下探成腿"还是"斜坡滑到地"？
4. **顶部**：是尖脊还是平盘？洞沿是否低于脊线？W99 宽度多少（图纸多少）？
5. **母线**：平视/正投影是直线还是弧线？残差多少？
6. **面层覆盖**：竹瓦盖到哪一圈？自由边以外是不是露出格网？玻璃是连续还是被挖了洞？
7. **构件连续性**：梁到柱有没有断头？有没有"悬空竹竿"？
8. **臆造件**：逐个数一遍构件，每件能不能在图纸/照片上指认？
   有基础件就必须有图纸依据。
9. **尺度**：屋脊高 / 最大跨度 / 与图纸比例尺换算值差多少？
10. **场地**：只留必需的（建筑 + 一块地坪）。广场、坐凳、石刻、绿篱**默认不建**。
11. **图层**：有没有空图层/遗留图层？图层色是不是材料色？
12. **出图**：同一组相机有没有被上次出图带偏？正交图是否单独脚本跑？

## 六、量化验收（别靠"看着还行"）

每次出图后必做，写进日志：

```python
# 1) 包围盒 —— 与图纸对表
bb = rs.BoundingBox(rs.AllObjects())
span = (max(x)-min(x), max(y)-min(y), max(z)-min(z))

# 2) 母线残差（纯 Python 复算，不依赖 Rhino）
#    对每个方位采样 -> 最小二乘拟合直线 -> 报最大残差
#    判定：一般方位 < 0.1 m；开口方位 0.3~0.8 m（拱腿下探，属设计需要）

# 3) 剪影宽度（从渲染图或点云算）
#    W95 / W99：99% 高度处的宽度。平盘 = W99 ≈ 洞口直径 -> 洞口没收尖

# 4) 像素占比（判"空/黑/白"）
#    背景取角落像素后要【排除地面】；否则深色地面会把均值拉偏
```

**踩过的坑**：曾用"角落像素当背景"量着色模式颜色，角落落在深灰地面上，
把整片地面算成模型像素 → 得出"着色恒为 159 灰、改不动"的错误结论，
并据此走错了一整轮方案。**关键结论必须换一种量法复核。**

## 七、默认交付形态（重要）

用户原话：**"自然建模结果无额外说明不要任何渲染"**。

所以默认 = ：
1. 图层色 = 自然材料色（上表调色板）
2. **不加对象材质**（加了会让文件涨 3.5 MB，且改变渲染观感）
3. 视口设为**着色模式（1）**，出图用 `CreatePreviewImage`
4. **不做**黑模 / 白模 / 纯色剪影 / 渲染样式 —— 除非用户明确要求

只有用户说"要黑的/要白的/要剪影/要体块图"时才切样式，见 `references/styling.md`。
